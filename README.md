# Lógica de Programação com TypeScript

Este repositório foi criado para documentar e organizar a minha evolução nos estudos de fundamentos de programação e lógica utilizando a linguagem TypeScript. Aqui estão reunidos exercícios práticos focados na construção de uma base técnica sólida e na compreensão dos tipos em JavaScript.

## Tecnologias Utilizadas

- **TypeScript** (4.0 ou superior)
- **Node.js** (para execução)
- **Prettier** (Formatação de código)
- **Git & GitHub** (Controle de versão e documentação)

## 📁 Estrutura do Repositório

O projeto está dividido em módulos temáticos para facilitar a navegação:

### `src/modules/basic-types/`

Fundamentos essenciais de tipagem e sintaxe TypeScript:

- **type-annotation.ts** - Anotação explícita de tipos
- **type-inference.ts** - Inferência automática de tipos
- **type-alias.ts** e **type-alias1.ts** - Criação e uso de aliases de tipo
- **type-array.ts** - Arrays tipados
- **type-tuple.ts** - Tuplas e readonly-tuples
- **type-enum.ts** - Enumerações
- **type-bigint.ts** - Trabalhando com números grandes
- **type-symbol.ts** - Symbol como tipo
- **union-types.ts** - Tipos união e type guards

### Tipos Especializados

- **object.ts** - Tipos de objeto e interfaces
- **literal-types.ts** - Tipos literais (específicos)
- **index-signature.ts** - Assinaturas de índice em objetos
- **readonly-arrays-and-tuples.ts** - Arrays e tuplas imutáveis
- **readonly-object.ts** - Propriedades readonly

### Funções

- **function-type-void.ts** - Funções sem retorno
- **function-return-type.ts** - Tipagem de retorno de funções
- **reduce.ts** - Método reduce com tipagem
- **reducemaior.ts**, **reducenames.ts**, **reduceproduct.ts** - Variações do reduce

## Como esses conceitos me ajudam hoje

O domínio de **tipagem em TypeScript** proporciona uma base sólida para:
- Capturar erros em tempo de desenvolvimento, não em produção
- Melhorar a legibilidade e manutenibilidade do código
- Facilitar a transição para outras linguagens tipadas
- Entender melhor a arquitetura de dados e fluxo de tipos em aplicações modernas
